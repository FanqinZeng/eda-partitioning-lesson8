# Lesson 8 多路划分自学讲义

分成三组，怎样少一点跨组沟通？

FanQin Zeng · EDA Learning

01 / 五位同学，分成三组

学习目标：能手算多路划分的割代价，比较轮询与递归二分，解释容量约束，并用一次参数修改验证自己的预测。

五位同学合作完成项目，频繁沟通的人若分在不同组，需要更多跨组协调。用节点表示同学，用带权无向边表示合作联系。生活情境为虚构教学设定。

| 对象 | 模型 | 本例规则 |
| --- | --- | --- |
| 五位同学 | A、B、C、D、E | 每个节点大小为 1 |
| 三组 | k = 3 个非空分区 | 每组容量上限为 2 |
| 合作联系 | 非负边权 | 跨区边权越少越好 |

完整输入与目标

边表：AB=5，AC=1，BC=4，CD=2，DE=5，CE=1。未列出的节点对没有边。本课使用加权无向图作为简化模型。

割代价 cut(P) 是所有端点处于不同分区的边的权重之和。每条无向边只算一次，组内边贡献 0。目标是：在满足三组非空、每组大小不超过 2 的方案中，让 cut 尽量小。

轮询基线：AD / BE / C

按 A、B、C、D、E 依次放进第 1、2、3、1、2 组。人数为 2、2、1，满足容量。六条边全部跨区，所以 cut = 5+1+4+2+5+1 = 18。

02 / 递归二分，逐步保留紧密联系

第一刀：ABCDE 分成 ABC 与 DE

先保留两团紧密联系，只切开 CD=2 与 CE=1，当前割代价为 3。ABC 含 3 个节点，它是待细分的中间块，尚未满足最终三路容量。

第二刀：只把 ABC 分成 AB 与 C

新切开 AC=1 与 BC=4，新增代价为 5。DE 不再拆分。最终叶子是 AB、C、DE，大小为 2、1、2。第一刀的边仍跨区，最终只计一次。

最终 cut = CD(2) + CE(1) + AC(1) + BC(4) = 8。也可按切分过程核对：第一刀 3，加第二刀新增 5，合计 8。

| 方法 | 最终分组 | 各组大小 | cut |
| --- | --- | --- | --- |
| 轮询 | AD / BE / C | 2、2、1 | 18 |
| 递归示例 | AB / C / DE | 2、1、2 | 8 |

为什么相差 10？

两种方案都使 AC、BC、CD、CE 跨区，合计 8。递归方案把 AB=5 与 DE=5 留在组内，而轮询把这两条重边也切开。因此差距是 5+5=10。人数同样接近平衡，并不能说明沟通代价一样。

直接改进示例：从轮询结果交换 D 与 B，得到 AB / DE / C，人数仍为 2、2、1，cut 降到 8。它展示直接多路改进的直觉，但不等于完整的 k-way FM。轮询也不能代表所有直接多路算法。

03 / 算法过程、容量与验证

轮询分配的教学伪代码

1. 把节点按名字排序，设置三个空组。
2. 节点和组都从 0 编号，第 i 个节点放入编号 i mod k 的组。
3. 输出节点归属、割代价、每组大小与容量检查。
它只看顺序，不看边权。若遇到面积不同的节点，还必须验证容量。

递归二分的教学过程

1. 从包含全部节点的一块开始。
2. 选择还需细分的块，在其诱导子图内进行二分。
3. 记录本次新切开的边与两个子块。
4. 达到 k 个叶子后，用完整输入图重算最终 cut。
5. 对每个最终分区检查容量，报告是否可行。

本课展示的切分树是 ABCDE 分为 ABC、DE，再把 ABC 分为 AB、C。一般实现还必须明确“选哪一块”和“如何二分”，相同名称并不保证相同结果。

| 设定 | 判断 | 原因 |
| --- | --- | --- |
| k=2，上限=2 | 必然不可行 | 总容量 4 小于节点总大小 5 |
| k=2，上限=3 | 可行示例 ABC / DE | 割代价为 3，属于另一套约束 |
| k=3，上限=2 | 本课问题 | 可行大小为 2、2、1 的排列 |

小图的穷举能证明什么？

本例可行的带标签分配有 90 个。先选择单节点组的标签和节点：3×5；再从其余 4 个节点中选 2 个给一个指定标签组：6 种，因此 3×5×6=90。枚举最小割为 8，忽略标签后对应 AB / C / DE。

这个最优性结论只针对当前五节点图。一般递归二分不保证全局最优，局部二分平衡也不自动保证最终统一容量。若单元面积不同，需累计面积；总容量足够仍只是必要条件。

04 / 用实验检验自己的解释

一次完整的实验记录

| 步骤 | 建议记录 |
| --- | --- |
| 读取输入 | 边表、k、节点大小、各组容量上限 |
| 运行与观察 | 每一步分组、跨区边、割代价、各组大小 |
| 公平比较 | 两方法使用同一张图及同样约束 |
| 改变条件 | 先写预测，再修改输入并重新运行 |
| 解释结果 | 说明变化来自哪些边，最终是否满足容量 |

参数挑战：把 AB 的权重从 5 改为 1

先比较同样的两个固定方案。轮询方案中 AB 跨区，因此代价减少 4，从 18 变为 14。原递归方案中 AB 是组内边，其代价仍为 8，差距变为 6。若重新运行算法，应重新检查输出的分组，不能预先假设它总会返回原方案。

报告示例

“我把 AB 从 5 改成 1。在固定分组 AD / BE / C 下，只有 AB 对割代价的贡献改变，所以 cut 从 18 降到 14。固定分组 AB / C / DE 的 cut 仍为 8。两方案均满足每组容量 2，差距从 10 变为 6。”

工程联系与边界

节点可近似表示电路单元，边可近似表示连接。真实 EDA 常需超图、面积、时序和拥塞模型。本例的单位大小只保持人数，不等价于工程中的面积平衡。对规模更大的图，优化方法还需处理搜索效率和可行性。

05 / 练习：先手算，再打开实验台

1. 列出轮询分组 AD / BE / C 的全部跨区边，计算 cut。

每条无向边只能计算一次。

2. 递归第一刀 ABC / DE 切开哪些边？割代价是多少？

说明为何这时还不是最终可行的三路结果。

3. 把 ABC 细分成 AB / C 后，新增代价是多少？最终代价是多少？

区分“新增边”与“已切开的边”。

4. 两种方案人数都接近平衡，为什么割代价相差 10？

指出恰好发生状态改变的两条边。

5. 从 AD / BE / C 交换哪两个节点，可以在保持人数时得到 cut=8？

写出交换后的完整分组。

6. 把 AB 权重从 5 改为 1，两个固定方案的代价与差距分别是多少？

固定方案为 AD / BE / C 与 AB / C / DE。

7. 若改成 k=2，但每组容量仍为 2，能否放下五个单位节点？

若上限改为 3，ABC / DE 的代价是多少？

8. “递归二分保证全局最优，只要局部平衡，最终容量就一定合法。”对吗？

解释本例穷举结论的适用范围，并讨论面积不同的节点。

06 / 练习解析与完成自查

1. 轮询割代价

AB=5、AC=1、BC=4、CD=2、DE=5、CE=1 全部跨区，合计 18。

2. 第一刀

只有 CD=2 与 CE=1 跨区，cut=3。此时只有两块，且 ABC 的大小为 3，需要继续细分。

3. 第二刀

新增 AC=1 与 BC=4，合计 5。最终 3+5=8。CD 与 CE 仍跨区，最终每条只算一次。

4. 差距来源

AB=5 与 DE=5 在轮询中跨区，在递归结果中属于组内。其他四条边的状态不变，因此相差 10。

5. 一次直接交换

交换 D 与 B，结果为 AB / DE / C，大小保持 2、2、1，cut=8。这只是直接改进示例，不是完整 k-way FM。

6. 改变 AB 权重

轮询固定方案为 14，原递归固定方案仍为 8，差距为 6。重新求解时，算法可能选择不同的划分。

7. 改变容量

不能。k=2、上限2时总容量为4，小于5。上限改为3后 ABC / DE 合法，其代价为 CD2+CE1=3。

8. 算法边界

该说法不成立。递归二分一般不保证全局最优，最终每组仍需检查容量。本图90个可行带标签分配的穷举证明最小值8，只适用于该输入。面积不同需按面积累计。

完成自查：我能区分“组数、容量、目标”，能逐边核算 18 与 8，能解释差距 10，能对一次输入修改先预测再验证，并报告输出是否可行。

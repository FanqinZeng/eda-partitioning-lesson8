02 / 从生活走到算法

人数分得开，联系也要顾得到。

1 / 规则

三个组，每组最多两人

每人对应一个节点，合作关系对应边，数字表示虚构的沟通频次。五人无法平均分成三组，2、2、1 就是这里的合理分布。

2 / 代价

只把跨组联系加起来

同一组内的边不计入代价。跨组边的权重相加得到 cutsize，每条无向边只算一次。把所有人放一起会违反分组要求。

3 / 方法

直接分配，或逐次二分

轮询按字母顺序轮流分到三个组。递归二分先分成两组，再切分当前最大的组，直到得到三个组。

同一个比较标准

割代价 = 所有跨区边权之和

目标是在满足分区数量和容量的前提下，让割代价尽量小。

ABC｜DE：3，AB｜C｜DE：8

第一次切开 C–D、C–E，代价 2 + 1 = 3；再切开 A–C、B–C，新增 1 + 4 = 5。最终共 8。

轮询是帮助比较的简单基线。直接多路优化还有更复杂的方法。递归二分也可能受早期切分影响，在其他图上未必更好或满足最终容量。

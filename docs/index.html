02 / 先分清：流程与每一刀

递归决定继续拆哪组，谱二分决定怎么拆。

1 / 问题

五个节点，三个非空组

每个节点大小为 1，每组容量为 2。边上的数字代表虚构的沟通频次；跨组边权相加就是割代价，每条无向边只算一次。

2 / 外层流程

一组变两组，重复到 k 组

本课每次选择节点最多的组，分成两个非空子组。每切一次，组数加 1，得到三组就停止。二分允许两边人数不同。

3 / 内层算法

按连接关系生成候选，再比较

先用当前子图的边权计算谱坐标，按数值排序。再沿这个顺序尝试切口，比较跨边代价，选合格候选中代价最小的一刀。

进阶：为什么是第二小特征值？实际代码怎样求？

给每个节点一个实数坐标 x，希望 E(x) = Σ wᵤᵥ(xᵤ − xᵥ)² 尽量小。权重大，两个端点相隔很远的代价就大。再要求 Σxᵤ = 0、Σxᵤ² = 1，固定中心和尺度，防止所有节点挤到一起。

把边权写成邻接矩阵 W，连接权重之和写成对角矩阵 D，令 L = D − W，则 E(x) = xᵀLx。对于本例的连通图，最小特征值 0 对应所有坐标相同；上述约束下的最优坐标是第二小特征值对应的 Fiedler 向量。

本课采用教师基线的数值近似：令 M = L + 0.001I，每轮用 40 次 Jacobi 扫描近似解 My = x，再对 y 减去均值并归一化，重复 80 轮。初始正负交替向量只是迭代起点。坐标整体乘以 −1 会把顺序反转，不改变对应的候选二分集合。

局部候选过滤要求左侧面积比例在 20%–80% 之间；若全部不合格，教师基线会沿排序在中间回退切分。最终 k 路容量仍需单独检查。有限轮迭代、重特征值或不连通输入可能使排序依赖初始向量；不能据此保证全局最优。

数学依据：Spielman 谱图理论讲义，第 2.3 节 · 本课实际数值代码
